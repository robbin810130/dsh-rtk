# dsh-rtk v1.3.2 — Windows 使用说明

纯文档版本，运行时逻辑与 v1.3.1 一致；无需为此升级（装与不装都不影响 Windows 上的功能）。

- 新增 `docs/windows.md`：
  - 四种 RTK 安装方式（winget / scoop / cargo / release zip）与各自的 `rtk.exe` 落点；
  - 默认自动发现的五条 Windows 候选路径；
  - 显式指定的两种方式：注册表用户环境变量（`setx` / `[Environment]::SetEnvironmentVariable`）与 profile 里 `config.bin`（含 YAML 反斜杠转义陷阱）；
  - 重启与验证步骤（`doctor` + 会话内 `$env:DSH_RTK_DISABLE='1'` 对照）；
  - Windows 专有排障：`$PROFILE` 无效、`.cmd`/`.bat` 被拒、路径含空格、doctor 看不到子进程 `RTK_BIN` 等。
- 明确标注平台差异：Windows 上 DSH 继承注册表环境而不读 shell 配置，且加载的是 `pwsh` 而非 `bash`。
- 该文档随包发布（`package.json` 的 `files` 增加 `docs/windows.md`）。
