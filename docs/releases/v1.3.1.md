# dsh-rtk v1.3.1 — 升级后不再谎报"已生效"

问题：装完新版本但还没重启时，运行中的宿主仍是旧版本，而 `doctor` 只检查"状态文件的 pid 是否还活着"，于是照旧输出「配置就绪」——正是它最该提醒的场景。

- 状态文件新增 `pluginVersion`（插件从自身 package.json 读取）。
- `doctor` 把该版本与 profile 里**实际安装**的版本比对：不一致时报 ❌「运行中的宿主加载的是 vX，而 profile 里已安装 vY → 完全重启 DSH 后新版本才生效」。
- 对 1.3.1 之前的旧记录（不含版本标记）退化为时间判据：宿主启动时间早于已安装包的写入时间，同样报 ❌ 并提示重启后精确核对。
- 运行时行为与 1.3.0 一致，无配置变更。
